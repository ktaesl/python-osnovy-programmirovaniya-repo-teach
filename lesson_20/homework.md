## Подсказки по частым ошибкам

1. **`=` вместо `==`** в условии — получите `SyntaxError`.
2. **`x == 1 or 2`** — всегда истинно. Правильно: `x == 1 or x == 2` или `x in (1, 2)`.
3. **Забытое двоеточие** после `if`, `elif`, `else`.
4. **Неправильный порядок `elif`**: сначала проверяйте самые строгие условия (самые высокие баллы, самые узкие диапазоны).
5. **`input()` возвращает строку.** Не забывайте `int()` / `float()` перед сравнением чисел.
6. **Отступы.** Тело ветки — строго 4 пробела, внутри вложенного условия — ещё 4.
7. **Граничные значения** (`>` вместо `>=`) — главный источник ошибок на контрольной.
8. **`or` вместо `and`** в диапазонах: `x >= 1 or x <= 100` истинно для любого `x`.
